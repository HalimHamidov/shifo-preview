Номера и цены

Номера

Наличие номеров зависит от дат и сезона. Для семьи, пары или одного гостя администратор подберёт подходящую категорию.

Стандарт

Для одного гостя или пары, которым нужен простой комфортный номер.

  • основные удобства
  • спокойное размещение
  • удобно для короткого отдыха
Уточнить наличие

Семейный

Для гостей, которые приезжают с детьми или старшими родственниками.

  • больше места
  • удобно для семьи
  • даты лучше бронировать заранее
Уточнить наличие

Улучшенный

Для гостей, которым важны дополнительное пространство и спокойствие.

  • комфортное размещение
  • подходит для длительного курса
  • наличие по запросу
Уточнить наличие

Комфорт

Для гостей, которые хотят более удобный формат отдыха и восстановления.

  • приятная обстановка
  • удобно для пары
  • вариант для продолжительного отдыха
Уточнить наличие

Цены указаны за 1 человека в день. В стоимость проживания включено 3-разовое полноценное питание.

Уточняйте наличие свободных мест и секций заранее по указанным телефонам.
